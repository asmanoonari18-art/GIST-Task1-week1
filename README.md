# GIST-Task1-week1
Project Description
Expense Tracker – Python Utility Application
The Expense Tracker is a beginner-friendly Python utility application designed to help users record, manage, and monitor their daily expenses. The application allows users to add expenses by entering the category, description, and amount. Users can also view all recorded expenses, calculate their total spending, and search for expenses based on categories.
The application uses Python functions, loops, conditional statements, lists, dictionaries, exception handling, and file handling. Expense data is stored in a JSON file so that the information remains available even after the program is closed. A simple menu-driven interface makes the application easy to use.
Main Features
•	Add new expenses 
•	View all expenses 
•	Calculate total expenses 
•	Search expenses by category 
•	Validate user input 
•	Save and load expense data using a JSON file 
•	Simple menu-driven interface 
Technologies Used
•	Programming Language: Python 
•	Data Storage: JSON file 
•	Concepts: Functions, loops, conditions, lists, dictionaries, file handling, and exception handling 
Objective
The main objective of this project is to practice fundamental Python programming concepts while developing a useful real-world utility application for managing personal expenses.
